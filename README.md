🟢 GREEN BIRD V2.0

Cyber Security & Website Analysis Tool

GREEN BIRD is a lightweight Python-based website security analysis tool designed for educational purposes and authorized security testing.

✨ Features

1. DNS Analysis – Retrieves domain IP addresses.
2. SSL/TLS Checker – Checks SSL certificates and expiration dates.
3. Security Headers – Identifies missing HTTP security headers.
4. Cookie Security – Checks Secure, HttpOnly and SameSite attributes.
5. HTTP Methods – Inspects the server's advertised HTTP methods.
6. HTTPS Redirect – Checks HTTP-to-HTTPS redirection.
7. Server Information – Displays publicly disclosed server information.
8. Robots.txt Analyzer – Checks and reads the robots.txt file.
9. Security.txt Checker – Checks for a security.txt file.
10. JSON Reports – Saves analysis results as JSON files.

📱 Requirements

- Python 3
- Termux or another Python environment
- Internet connection

No external Python packages are required.

🚀 Installation

Clone the repository:

git clone https://github.com/USERNAME/Green-Bird.git

Enter the project directory:

cd Green-Bird

Run GREEN BIRD:

python greenbird.py

📊 Reports

GREEN BIRD automatically generates JSON reports containing the results of its checks.
